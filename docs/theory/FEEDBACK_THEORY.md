# 相同边际不足以决定标准化信用：理论主线与证明

## 状态与合同

本文件为可修订的理论说明；v4 与 Pro 原文单独按 hash 归档，不改写原文。
证明是自含数学推导，不等于形式化证明、同行评审或 LLM 效果证据。

固定 prompt、checkpoint、公共支持；actor Y_i IID；整个配置向量 U 与整个 Y 向量独立，
私有评分随机性独立。S(Y)=∇ log π(Y)，E S=0，配置分布与奖励通道在求导时固定。
每组完整保留。主估计量 G=K^{-1}∑ A_i S_i，优化器映射为预先冻结的线性 M。
原始序列 score 包含实际 EOS，截断不补 EOS。

新旧主线仅改变依赖的位置：旧稿改变回答联合律，新稿保持回答 IID、改变评分配置联合律。
因此旧 W/C/X 的 RLOO 偏差不得搬到新 S/I 分支。

## 一般固定银行刻画（有限奖励，强量词）

设有限奖励集合 R，K≥2，A:R^K→R^K。以下三个要求合起来，等价于 transformed RLOO：

- 对任意坐标置换等变；
- 对每个奖励向量逐点零和；
- 对**每一个边际元组** (ν_1,…,ν_K)，任意拥有这些逐坐标边际的联合律 Q,Q'，
  对所有 i 都有 E_Q A_i=E_Q' A_i。

此时存在 f:R→R，使

    A_i(r) = f(r_i) − (K−1)^{-1} ∑_{j≠i} f(r_j).

f 仅确定到加法常数。边际元组各坐标可以不同；这里只要求 Q 与 Q' 对应坐标边际相同。
此性质比“只比较 S 与 I”强，也比“只在某个共同边际或 exchangeable 联合律下比较”强。
特别地，若只考察 exchangeable 联合律，等变加逐点零和就会令所有 E A_i=0，条件失去识别力。
不能将这里的必要性误报为仅测试 S/I 后得到的一般结论。

### 证明

固定输出坐标 i，以及不同输入坐标 j,l，其余输入固定为 z。
取 Q 分别在 (a,c,z)、(b,d,z) 上放置 1/2 概率，Q' 在 (a,d,z)、(b,c,z) 上放置
1/2 概率。逐坐标边际相同，因此 h=A_i 满足所有矩形混合差为零。

选基准值 r0。矩形差为零意味着改变坐标 j 所引起的 h 增量，与其他坐标取值无关。
从全 r0 逐坐标替换得到

    A_i(r)=c_i+∑_j h_ij(r_j),  h_ij(r0)=0.

此 anchored 分解唯一。置换等变推出 c_i=c、h_ii=a，所有 j≠i 的 h_ij=b。
在全 r0 向量上，零和给出 Kc=0。再只改变一个坐标为 t，零和给出

    a(t)+(K−1)b(t)=0.

代回即得结论，取 f=a。反方向由线性期望直接成立。□

这是固定边际 Fréchet 类上可加函数结构的 estimator 推论，不申报其纯线性代数为新发明。
当前有限表 CPU 检查覆盖 (K,|R|)=(2,2),(3,2),(4,2),(2,3),(3,3)，构造整个约束矩阵，
验证解空间维数 |R|−1；它验证有限实例，不能替代上述一般证明。

### 原始奖励目标保持的唯一性

在 IID actor 与外生配置下，transformed RLOO 的平均更新为 E[f(R)S]。
若要求一个固定常数 c 对**所有**策略及反馈通道都满足 E[f(R)S]=c E[RS]，
取在任意 a,b∈R 上输出的二类 actor、令反馈确定地取 a,b，就得到

    f(a)−f(b)=c(a−b).

因此 f(r)=cr+b，A 是 c 倍原始 RLOO。反方向立即成立。
c 可以为零或负；保留奖励上升方向还需 c>0。若允许 c 随任务/通道任意变化，
不能直接使用这一全局目标保持结论。连续奖励集合也可逐有限矩形推广点态代数，
但期望结论另需可测性与可积性；本实现的完整表检验仅覆盖有限空间。

## 交互分解与关联敏感度

在全支持乘积参考测度 λ=⊗ λ_j 上，定义

    A_i^marg = ∑_j E_λ[A_i | R_j] − (K−1)E_λ[A_i],
    A_i^int = A_i − A_i^marg.

这是乘积测度下一阶 ANOVA 投影；交互项是所有二阶及以上项的合计，不仅是 pairwise 项。
每个 E[A_i^int|R_j]=0。不同参考 λ 给出的分解不同，但固定边际下

    E_Q A_i − E_Q' A_i = E_Q A_i^int − E_Q' A_i^int.

故 RLOO 交互为零；二值 standardized 在 K=2/3 逐样本为固定倍 RLOO，交互为零；
K≥4 一般非零。多值奖励在 K=2 即可出现非零交互。

D_i(ν)=sup_{Q,Q'∈C(ν)} |E_Q A_i−E_Q' A_i|。
固定有符号功能方向 z_i 时，对 c(r)=K^{-1}∑ A_i(r)z_i 求两个 LP 可得精确有限维包络。
欧氏向量范数的 supremum 不是一次标量 LP；需对方向进一步优化，不能将标量包络直接称 D_L。
包络允许逐银行选择耦合，是外生统一配置族的宽松上界，不证明存在可部署的统一干预。

## 一般奖励的大组极限

令 R_i|U=u 条件 IID，|R|≤B，ε>0，E||S||<∞，且 U 与 Y 独立。
这是足够条件；只写“有限二阶矩”而不补 score 的可积性不够。
令 μ_u=E[R|u]、σ_u²=Var(R|u)、g_u=E[RS|u]。

由交换性，G_S^(K)=E[(R_1−R̄_K)S_1/(s_K+ε)]。
给定 u，强大数律令 R̄_K→μ_u、s_K→σ_u。
被积量范数≤2B||S_1||/ε，可积；条件及无条件 dominated convergence 给出

    lim G_S^(K) = E_U[g_U/(σ_U+ε)].

这里 E[(R−μ_u)S|u]=g_u，因为 E[S|u]=0。
I 情形中 (Y_i,U_i,ξ_i) IID，完全同理：

    lim G_I^(K) = ḡ/(σ_mix+ε),
    σ_mix² = E[σ_U²] + Var(μ_U).

若 σ_u=0，则给定 u 奖励常数、g_u=0，项仍有定义。ε=0 不能使用同一支配界，
需要额外的逆方差与一致可积条件；本项目不声称该无条件推广。
因此连续奖励的关联效应不只是小 K 现象。它仍不说明共享或独立谁更有益。

## 二值有限组公式与边界

v4 §3 的 b_m^±、w_K,ε(p) 原式保留。条件化得到

    G_S=E_U[w(p_U)g_U],   G_I=w(p̄)ḡ.

w 的正性不排除不同配置梯度互相冲突。Cov_U(w,g) 非零可能仍共线，
必须报告有符号平行系数，以及最佳**非负**缩放残差。逐 prompt 正缩放也可改变聚合方向。

RLOO 只有 **mean-update invariance under exogenous verifier coupling**；
方差、高阶矩、Adam 状态与有限步轨迹仍可能不同。

固定银行中每个候选的 q_i 独立保留，独立配置下伙伴计数用 Poisson-binomial，
不是用当前组平均 q 代入 Binomial，也不是标准化平均 reward。
均匀保留 m 个等权二值 criterion 使用整数 (T,Q) DP；非网格有限支持使用有界枚举，
超计算上限明确失败，不悄悄舍入或变成 Monte Carlo。

v4 的四回答反转是存在性证明。自然 suite-correct 程序通过每个子测试，
不能预设自然场景必须出现该反转。对称共享标签翻转和 K=2/3/RLOO 是阴性对照。

## 学习后果与统计

主要证据顺序：独立目标斜率 → 冻结功能读出 → 实际 η/η/2 变化 → 正缩放残差 → 参数 cosine。
同银行精确积分不是独立总体预测；缓存 judge 对已实现的反馈通道精确，未积分 live judge 的私有噪声。

独立 C、D：T̂=h̄ᵀ M Δ̄。完整 H_dc 可独立行列 bootstrap，但不作为廉价 pilot 必需项。
低存储时保存 a_d=h_dᵀMΔ̄、b_c=h̄ᵀMΔ_c。令 Î 是样本协方差收缩
tr(Σ̂_h M Σ̂_Δ Mᵀ)，则无偏方差估计为

    Var_sample(a)/n_D + Var_sample(b)/n_C − Î/(n_D n_C).

减号是因为代入另一银行样本均值时，两个投影方差项各自已含交互噪声一次。
总体以真实均值定义的方差分解中第三项是加号，二者不冲突。
未估 Î 时只能报告 first-order 近似且无完整 CI，不宣称传播了全部 D 不确定性。
有限样本无偏方差估计可能负；不截成零后伪造显著性。

候选/组重复不能扩大 prompt 的有效样本量。32 题仅 pilot；扩样依据实际方差、预定最小效应，
一次计划并记录。范数在零点有偏，不用普通 percentile bootstrap 排除零就声称非标量效应。

## 研究定位与最近邻（专项核验，不做广泛重搜）

- Davis–Recht 的 IID 二值权重和变换目标属于已有工具，不能声称首次发现 w(p)。
- [An Imperfect Verifier is Good Enough](https://arxiv.org/html/2604.07666v1)，§3.1 已比较
  sample/group × test/rollout 噪声。由构造推知部分配对具有相同逐回答通道，不能再称首次研究评分关联。
- [Rubric Dropout](https://arxiv.org/html/2608.11669v1)，Appendix A 明确其期望保持分析在组标准差除法之前。
  新主线检验标准化之后的均值与后果；不据此否定其训练结果。
- [Spurious Advantage Hidden in GRPO](https://arxiv.org/html/2609.04063v1) 已讨论二值计数组成决定幅度。
- [GRPO as a U-statistic](https://arxiv.org/html/2603.01162v3) 已有方差/有限样本分析，不能把一般方差分解申报为原创。

这里仅核验相关段落，未证明文献穷尽或 novelty 唯一。完整一般定理的先行数学表述仍需投稿前专项检索。

Pro 建议的处理：采用一般定理、连续大组极限、真实 rubric factorial 的代码准备，
去掉完整 H 的 pilot 硬要求。代码与 rubric 各自预注册；代码 pilot 阴性不能自动改选 rubric 阳性。
无预训练结果前不把 rubric 的潜在价值写成已成立的机制贡献。
