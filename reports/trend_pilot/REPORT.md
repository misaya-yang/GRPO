# v5.1 真实模型小规模实验报告

日期：2026-09-07。状态：**完成，INCONCLUSIVE**。本轮没有训练更新。

Strat-full 对 IID-all 的完整 LoRA 梯度方差比为 **0.9209**，计入宏组耗时后为 **0.9024**。点估计偏向分层，但区间宽，且方向会随删去一道题或一个宏组改变。**尚未确认稳定收益，也未排除有用收益；收益弱或不稳定的机制原因尚未定位。**

## 奖励诊断的准确解释

严格规则下 IID 正确 99/128，Strat 102/128。两臂共 55 条零奖励中，33 条截断、20 条格式失败、2 条完整有效答案数值错误。

事后允许唯一完整标签之后有文字、仍保留 EOS 要求，会恢复 19 条含正确数值的格式失败；IID 变为 111/128，Strat 109/128，正确率仍接近。**这不能说明严格评分是两臂没有稳定方差收益的主因。** 先前将格式/截断当作主要原因的解释证据不足，已在本报告修正。

奖励规则预先定义更新目标，不是结果反向决定奖励。换规则会改变组内优势和加权梯度，因此不能把新评分计数与旧梯度混用；但不妨碍解释原规则下已经测得的方差。两臂同一未训练 checkpoint、边际分布相同，期望正确率本来相同；真正待验证的是方差与成本，而不是单批正确数。

层间奖励率也不是梯度信息的充分统计量。当前缺少逐回答 score / 层间影响函数读出，不能定量区分分层信息弱与有限样本高阶代价。现有理论不保证 Strat-full 普遍胜过强 IID，因此不存在由本结果直接引出的理论矛盾。

## 工程结果与验证

1. 修复浮点 CDF 尾部质量错误和 latent refinement 控制流，保留输入 binary64 权重的精确归一化比例。
2. FP32 路径解决实际模型采样/回放 logp 不一致。小实验最大 token / sequence 误差为 0.0001391 / 0.0004366，低于原容差。
3. 向量化整数 CDF 的同输出重放将一个宏组成本减半；这属于实现速度改善，不是分层方法收益。
4. 提交前 CPU 检查：139 项测试通过，`make lint`、`make exact` 通过。独立离线脚本核对 rows/progress hash、原评分、权重、已存 Gram 的比值和区间通过；本次没有重新加载模型验证梯度张量。

本轮不能代表在线训练效果。历史准备回执中的运行中状态和源码 hash 按当时快照保留。
