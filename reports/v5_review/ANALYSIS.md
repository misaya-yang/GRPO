## 2. D 正点估计主要受未中心化 score 影响

固定 C 差分方向 d=Ghat_S,C−Ghat_I,C，记 z_i=S_i^T d。当前 D 估计器是逐 prompt 等权的 mean(r_i z_i)。在原始策略满足 score 恒等式时 E[z|x,C]=0，故独立于当前回答的 baseline b 不改变 E[(r−b)z]。

观测量：

- D 32 条中31条通过全部测试；3/4个prompt的8条回答全部通过。
- 这三个全通过 prompt 对总体点估计贡献 +87.45402748；有一条失败回答的 prompt 贡献 −5.46129481，总和 +81.99273267。
- 全通过的有限样本中，原估计器仍保留 mean(z)。这在期望上为零，有限样本中可很大；没有 baseline 就无法有效抑制这一项。
- Mbpp/409:0:0 单条贡献 +85.11101439。仅作敏感性诊断，去掉该条并保持 prompt 等权后为 −4.72563587。原主估计没有删除任何样本。
- 该回答83 tokens，同题其他回答80–85 tokens；不是长度极端值。它有额外代码围栏，但现有总 score 投影不足以判断是哪个 token 导致大贡献，不能据此确诊格式问题。

这是本轮设计/实现应改进的估计效率问题。它不是已证明的均值偏差，也不能据此断言真实奖励梯度为零。奖励接近饱和加上少量 prompt，使当前方向估计非常脆弱。

### 可用现有银行补做的最小诊断

同一 prompt 的 D 回答 IID，C 与 D 独立，因此使用 leave-one-out baseline

    a_i = r_i − (K−1)^{-1} sum_{j≠i} r_j

仍无偏估计原始 reward 梯度。不能用包含自身的组均值后忽略其有限样本缩放。

三个全通过 prompt 的 RLOO 样本贡献恰为0。唯一混合组 Mbpp/474 中，成功回答权重为1/7、失败回答为−1。根据已保存投影：

    T_RLOO = −0.7801849729962018 − z_fail/32,
    z_fail = S(Mbpp/474:0:7)^T d.

当前脚本为原始 r*z 目标省去了零 reward 行的反传，明确把该行标记为未测量。因此 z_fail 现在未知，不能从占位0伪造 RLOO 结果。未来只需补一个缺失的方向投影，即可重构这个中心化诊断，无需重新生成32条回答。加载权重/梯度仍有实际开机成本。

中心化是无偏结构，不保证任意固定 b 都降方差；方向上最优独立标量 baseline 为 E[r z²]/E[z²]（分母非零）。估计它必须与被评估回答独立，或给出正确的交叉拟合/LOO 合同。不要在当前 D 结果上选择最有利的 baseline 后当作新确认结果。

## 3. 步长未通过的更准确解释

η=1e-4、η/2=5e-5 的相对残差为1.02998、0.69919；绝对残差范数为0.379152、0.128691，缩小约2.946倍。这支持继续检查更小步长，不构成已证实的二阶规律。

我此前将原因简写成“步长过大”。更准确是：这两个步长没有进入已经验证的局部线性区间；共同更新方向的曲率是一个有数据支持的解释，尚缺更小步/中心差分来完成定因，不能把实现或数值因素全部排除。

设 d_S,d_I 是两臂方向，Delta=d_S−d_I，m=(d_S+d_I)/2。F 为 C³、方向固定时：

    F(theta+eta*d_S)−F(theta+eta*d_I)
    = eta*DF(theta)*Delta + eta²*D²F(theta)[m,Delta] + O(eta³).

因而余项并不只由 ||Delta||² 控制。在 Hessian 范数≤L 的局部区域内，还可写出

    ||remainder|| ≤ (L*eta²/2)*(||d_S||+||d_I||)*||Delta||.

独立臂在η=1e-4下的两个函数一阶变化约−3.97136、+1.08586，而两臂差的一阶变化约−0.34710、−0.12261。共同位移比所比较差值大；用差值做相对残差分母也容易放大取消效应。下一轮应同时报告共同方向位移、绝对余项、差值相对余项及数值误差底线。

已准备更小步长计划，但现在保持未运行状态。仅缩小 eta 不能解决 D 的高方差问题，两者要分开处理。

## 6. v5 需要优先复核的更强分层估计器

v5§5.1的独立分层实例满足：对每个层j，Z_bj在b上IID；各层之间也独立。因此真实样本在已知层标签下相互独立。跨块重组禁止来自同一块不同层的两条回答同时进入虚拟组，可能只是任意配对留下的限制。

固定已生成的各层样本，分别随机置换每层的块编号，再计算原 Strat-cross，并对所有置换取平均。记结果为 T_reblock。由于每层样本交换性，这等于对原估计器关于各层无序样本作条件期望，故

    E[T_reblock] = G_K,
    Cov(T_reblock) <= Cov(T_Strat-cross)  （Loewner序）.

这是独立分层实例的推导草稿；不适用于任意相关块、共享随机数或共享组依赖 judge。它保留原始边际 score，并不对分层条件概率求导。

对对称核H、B>=K，其显式形式为：对所有k_1+...+k_m=K，使用权重

    K! / (m^K * product_j(k_j!)),

再在每个层内均匀取k_j个不同实际样本，对所有层内子集组合平均H。它允许不同层选到原来同一块的样本，因为这些样本在该实例中确实独立；也不等于把分层银行直接当IID后做普通IID-all。

## 7. 给 Pro 的优先问题

1. **强分层估计器与主算法选择。**逐步证明上述重配对条件期望与层内完整U形式；核查哪些采样/反馈条件使其适用。比较其与v5 Strat-cross、IID-all的精确方差、成本和可计算权重。若支配关系成立，v5为何仍以较弱Strat-cross为主要实现？一般块鲁棒性是否值得该代价？
2. **恢复D估计效率与双银行推断。**为固定C方向给出原reward目标的合法独立/LOO baseline、最优系数及近饱和情形方差；推导使用有限prompt和独立宏批时的C/D不确定性。明确哪些需要补测，不能给缺失z_fail填值或仅靠截尾改变主估计。
3. **共同方向的局部曲率。**核验差分Taylor式，设计中心化差分、共同中点及较小eta验证，区分曲率、差值取消和数值误差。不能把标准SGD smoothness界当作真实两臂一步收益排序。
4. **自然分层是否真的划分了更新影响。**在K4、B4/8、m2的真实算术分层下分析psi和高阶层收益；给出独立校准能预测的胜负量，而非仅看reward counts。将参数空间、LoRA初始化退化和有限精度release机制纳入实际条件。
5. **新颖性与更强资源参照。**与product-form、分层U-statistic逐项对照，明确RL特定可计算结论。完整分层估计器也需对比同预算更多prompt；不要只证明比普通split好。

建议先让Pro审第1项。它影响v5主算法和基线，直接照现方案投入GPU可能需要重做。第2/3项是可以定位并补测的实验方法问题，当前没有证据表明v4核心恒等式被推翻。

## 8. 近邻文献的有限核验

- Kuntz, Crucinio, Johansen 的 [Product-form estimators](https://arxiv.org/html/2102.11575v3) 明确将该类估计器连接到generalized U-statistics，并讨论方差与计算成本；不能将一般乘积经验测度或Rao–Blackwell化申报为新工具。
- [Generalized U statistics for stratified random samples](https://www.tandfonline.com/doi/abs/10.1080/03461238.1973.10414969) 的出版记录与摘要已涵盖分层U-statistic、方差、分配与最优分层；本次未取得全文，不声称其定理与本推导完全等价。作者为Taga、Wakimoto、Yanagawa，v5参考表应补全作者。
